# Proyecto Aurora.
## Descripción.
Proyecto Aurora es una herramienta de línea de comandos diseñada para automatizar la gestión de tareas diarias, optimizar el flujo de trabajo de los desarrolladores y organizar proyectos de manera eficiente.
## Objetivos.
- Simplificar y automatizar tareas repetitivas del sistema.
- Mejorar la productividad general del usuario final.
- Poder ocupar el tiempo ahorrado en otras tareas esenciales.
## Instalación.
Para instalar esta herramienta en tu distribución basada en Debian o Ubuntu, simplemente abre tu terminal y ejecuta el siguiente comando:
`sudo apt-get install proyecto-aurora`
